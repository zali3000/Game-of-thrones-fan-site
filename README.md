# Westeros Chronicle — Reorganized Website

This version keeps the original dark Westeros visual identity while restructuring the project for easier development in VS Code.

## Structure
- `index.html` — era selector/home
- `got/` — Game of Thrones pages
- `hotd/` — House of the Dragon pages
- `css/main.css` — shared styles and components
- `css/got.css` — Game of Thrones theme
- `css/hotd.css` — House of the Dragon theme
- `js/main.js` — navigation, animations, search/filtering and character profiles
- `about.html` — project information, gallery and FAQ

## Added
- Responsive hamburger navigation
- Search on content pages
- Faction filters for House of the Dragon content
- Character profile modal
- Gallery sections
- FAQ sections
- Scroll-reveal timeline behavior
- Shared CSS/JavaScript instead of repeated inline code
- Cleaner folder structure and corrected relative navigation paths
