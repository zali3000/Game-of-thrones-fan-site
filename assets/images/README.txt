WESTEROS IMAGE GUIDE

Each GOT and HOTD section now has its own background image slot.

Background folders:
assets/images/backgrounds/got/
assets/images/backgrounds/hotd/

Replace a background file with your own JPG/PNG while keeping the filename (or update the CSS path if you rename it).

Examples:
- backgrounds/got/cities-bg.jpg = GOT Cities page background
- backgrounds/hotd/dragons-bg.jpg = HOTD Dragons page background
- backgrounds/got/characters-bg.jpg = GOT Characters page background
- backgrounds/hotd/characters-bg.jpg = HOTD Characters page background

The main WESTEROS home page now asks visitors to choose GOT or HOTD whenever they click a section such as Characters, Houses, Dragons, Cities or Chronicle.

All inner pages keep a BACK TO WESTEROS HOME link.
